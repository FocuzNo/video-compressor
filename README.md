# Сжать — браузерный видеокомпрессор

## Summary

Веб-приложение для сжатия видео до выбранного размера в МБ или ГБ. Пользователь выбирает файл, задаёт максимальный размер и скачивает результат в MP4. Обработка выполняется на устройстве пользователя через FFmpeg WebAssembly; видео не отправляется на сервер.

Интерфейс на русском языке, адаптирован для компьютеров и телефонов. Проект работает как обычный статический сайт: без серверной обработки, регистрации и сборки.

## Запуск через localhost

Нужны Python 3 и современный браузер с поддержкой WebAssembly и Web Workers.

```bash
git clone https://github.com/FocuzNo/video-compressor.git
cd video-compressor
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

На Windows вместо `python` можно использовать `py`.

Откройте **http://localhost:4173/**. Оставьте терминал работающим; для остановки нажмите `Ctrl+C`. Открывать `index.html` через `file://` не нужно: фоновому обработчику требуется HTTP-сервер.

## Как использовать

1. Нажмите **«Выбрать видео»** или перетащите файл в окно.
2. Укажите размер в **МБ** или **ГБ**, меньший исходного. При выборе файла автоматически предлагается половина его размера.
3. Нажмите **«Сжать видео»** и дождитесь завершения. Вкладку нужно оставить открытой.
4. Нажмите **«Скачать MP4»**. При необходимости обработку можно отменить.

Целевой размер — верхняя граница, а не требование заполнить файл ровно до неё. Результат может быть меньше. Если файл превышает лимит, приложение уменьшает битрейт и повторяет кодирование, максимум три попытки.

## Возможности

- MP4 с видео H.264 и звуком AAC, если у исходника есть аудиодорожка.
- Автоматический подбор битрейта и разрешения по длительности и целевому размеру.
- Фоновая обработка в Web Worker, прогресс и отмена.
- Однопоточная сборка FFmpeg: `SharedArrayBuffer` и специальные COOP/COEP-заголовки не требуются.
- Чтение исходника частями через WORKERFS без полного копирования входного файла в память WebAssembly.
- Проверка параметров через FFprobe, сообщения об ошибках и повторный запуск.

## Ограничения и приватность

Движок `@ffmpeg/core@0.12.10` загружается с jsDelivr, поэтому для его загрузки нужен интернет. Само видео обрабатывается локально: код приложения не загружает его на внешние серверы. Полностью автономный офлайн-режим не реализован.

Сжатие с потерями: уменьшение размера может снижать качество и разрешение. Разрешение автоматически ограничивается диапазоном до 1080p в зависимости от битрейта, увеличение высоты исходного видео не выполняется. Сохраняются первая видеодорожка и первая аудиодорожка; субтитры и дополнительные дорожки не переносятся.

Скорость и допустимый размер ограничены процессором и памятью браузера. Выходной файл хранится в памяти. Работа с произвольными многогигабайтными файлами не гарантируется; обработка длинных роликов может занимать много времени. Некоторые кодеки и повреждённые файлы могут не поддерживаться.

## Структура

```text
dist/
  index.html  # Интерфейс и адаптивные стили
  app.js      # Выбор файла, настройки, Worker, прогресс и скачивание
  encoder.js  # FFmpeg, FFprobe, чтение файла и кодирование
```

Для размещения на своём сервере достаточно раздавать содержимое `dist/` по HTTP или HTTPS. Сервер должен корректно отдавать JavaScript-файлы и разрешать загрузку движка с jsDelivr, если используется Content Security Policy.

## Проверка

В браузере проверены два последовательных сжатия синтетического пятисекундного ролика со звуком: **2 122 968 → 132 697 байт** при лимите **157 286 байт**. Метаданные результата читаются браузером; длительность — около 5,015 секунды. Это проверка короткого тестового ролика, а не гарантия обработки всех форматов и больших файлов.

## Сторонние компоненты

Используется [FFmpeg.wasm](https://github.com/ffmpegwasm/ffmpeg.wasm) и его сборка [FFmpeg core](https://github.com/ffmpegwasm/ffmpeg.wasm/tree/main/packages/core). Лицензии FFmpeg и включённых кодеков применяются отдельно; бинарные файлы движка в этом репозитории не распространяются.
